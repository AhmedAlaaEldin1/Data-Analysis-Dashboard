# 🚀 Power BI Project: Comprehensive Sales Analysis Dashboard

This is a comprehensive sales analytics dashboard built using Power BI Desktop. It helps decision-makers visualize and analyze key metrics across products, regions, and sales representatives.

## 🎯 Objectives

- Identify top-performing products and sales reps
- Analyze monthly, quarterly, and YoY sales trends
- Understand return rates and their impact on profit
- Provide a clean, interactive dashboard for business use

## 🧰 Tools & Techniques

- **Excel:** Initial data cleaning and formatting
- **Power Query:** Advanced ETL steps, merging, conditional columns
- **Power Pivot:** Data model design and base DAX measures
- **Power BI Desktop:** Visualizations, relationships, KPIs, custom calendar

## 📊 Key Features

- **Sales Trend Analysis:** YoY growth, seasonal patterns
- **Product Performance:** Top/bottom product metrics
- **Rep Performance:** KPIs like margin and return rate per person
- **Custom Calendar Table:** Enables advanced time intelligence
- **Interactive Slicers:** Filter by region, category, time, and rep

## 📂 Data Model

- **Orders Table:** Main transactional data
- **People Table:** Sales reps and regions
- **Calendar Table:** Custom-built for DAX time intelligence
- **Measures Table:** DAX calculations centralized
